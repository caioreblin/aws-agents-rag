## Critério de "pronto" da Fase 1
R1–R7 satisfeitos — usuário autenticado dispara uma tool via MCP e recebe resposta
correta; adicionar uma tool não altera o núcleo. Ao fechar, gerar o spec da **Fase 2**
(Memória + RAG).
